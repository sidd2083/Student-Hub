# ADDITIONAL PRE-LAUNCH IMPROVEMENTS

## 1. CHAT SLOW MODE SYSTEM

The Study Room chat needs moderation tools.

Add a default chat cooldown.

Default:

* 1 message every 10 seconds per user

Purpose:

* prevent spam
* keep chat clean
* keep study environment focused

Users should see a cooldown indicator if they try to send messages too quickly.

Example:

"Please wait 8 seconds before sending another message."

---

## 2. CHAT VOTING CONTROLS

Add new democratic voting options.

### Enable Slow Mode

Vote Type:

Enable Slow Mode

Options:

* 10 sec
* 20 sec
* 30 sec
* 60 sec

If vote passes:

Room chat cooldown updates.

---

### Disable Slow Mode

Vote Type:

Disable Slow Mode

If vote passes:

Chat returns to default behavior.

---

### Disable Chat

Vote Type:

Disable Chat

If vote passes:

Nobody can send messages.

Existing messages remain visible.

---

### Enable Chat

Vote Type:

Enable Chat

If vote passes:

Chat becomes available again.

---

All chat controls must use the same democratic voting system as:

* Extend Time
* Pause Timer
* Resume Timer
* Kick User
* Remove Host
