1. ROOM CAN EXIST WITHOUT HOST (CRITICAL)
   ========================================================

Current bug:

Host creates room.

For some reason host never successfully joins.

Room still appears active.

Room shows:

* 1 member
* active room

But actually:

* no host exists
* no real member exists

Result:

Users can enter a room that has no host.

Voting becomes broken.

Room logic becomes broken.

Required fix:

A room must NEVER exist without a valid host.

Validation:

If room creator fails to join:

* delete room automatically
  OR
* do not create room until creator joins successfully

Room must always have:

* valid host
* valid member count

No ghost rooms.

6. DOUBLE TIMER EXPLOIT PREVENTION
==================================

Critical issue.

Current possibility:

User enters Study Room.

User also starts personal Pomodoro timer.

Result:

Same study session can be counted twice.

This can break:

* leaderboard
* report card
* daily tasks
* achievements
* streaks

Required:

Only ONE study source can count at a time.

Example:

If user is inside active Study Room:

* room timer counts
* personal pomodoro timer does NOT count

If user is using personal pomodoro:

* pomodoro counts
* room timer does NOT count

Prevent double counting everywhere.
