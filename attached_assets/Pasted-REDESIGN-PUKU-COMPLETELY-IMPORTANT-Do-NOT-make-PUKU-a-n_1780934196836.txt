* Do not use Firestore.

PUKU should feel like a friend studying with the user.

Not a chatbot.

Not a teacher.

A study companion.

---

## INTELLIGENT DISTRACTION DETECTION

Current behavior is bad.

Do NOT show warnings every minute.

Instead:

If user switches tab:

* Start monitoring.
* Do not immediately warn.

After 5 minutes outside Student Hub:

Show ONE warning.

Example:

"Still studying?"

Buttons:

[ Yes, I'm studying ]
[ I'm distracted ]

IMPORTANT:

If user clicks "Yes, I'm studying":

* Continue session.
* Do not show another warning immediately.

Wait another meaningful period before checking again.

If user ignores the popup completely:

* Pause study timer.
* Pause room timer contribution.
* Pause productivity tracking.

Only resume when user confirms they are studying.

This should work similarly to Pomodoro anti-cheat.
